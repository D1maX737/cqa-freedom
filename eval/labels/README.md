# Ручная разметка эталона

Здесь лежит по файлу на каждого размечающего: `<имя>.json`. Файлы пишет сервер, когда вы
сохраняете разметку на странице «Точность → Размечать». Коммитьте свой файл и делайте
`git pull`, чтобы видеть разметку остальных: конфликтов не будет, у каждого свой файл.

Разметка слепая: на странице разметки нет ответов модели. В файлах только идентификаторы
диалогов и ответы людей, текста диалогов нет.

Формат: `{ "labeler": "дима", "labels": { "<conversation_id>": { "checklist_version_id": "v1",
"labeled_at": "…", "criteria": { "c1": { "value": "yes" }, "c6": { "value": "7", "disputed": true, "note": "…" } } } } }`.
Значения те же, что в чек-листе: `yes`, `no`, `na` или балл шкалы; у грубой ошибки — `yes` или `no`.
